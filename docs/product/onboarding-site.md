# Parte 18 — Onboarding de um Novo Site `[PROPOSTA]`

### 97. Fluxo de cadastro de site `[PROPOSTA]`

```
Administrador cria o site
      ↓
Preenche: nicho, idioma, público, tom
      ↓
Define categorias iniciais
      ↓
Define interesses / não-interesses
      ↓
Configura conexão WordPress (URL, usuário, credencial)
      ↓
Vincula Redator-Chefe responsável
      ↓
(Opcional/futuro) Configura Notebook de conhecimento — ver seção 40
      ↓
Site pronto para receber metas e entrar em produção
```

> Este fluxo complementa a [Estrutura editorial de cada site (seção 15)](../editorial/fluxo-editorial.md#15-estrutura-editorial-de-cada-site) e a [Configuração específica do site (seção 20)](../editorial/fluxo-editorial.md#20-configuração-específica-do-site).
