# Glossário do projeto

### 79. Glossário do projeto

- **Site** = um WordPress gerenciado pela plataforma.
- **Redator-Chefe** = usuário responsável pela operação editorial de seus sites.
- **Meta** = objetivo de quantidade e direcionamento editorial para um período.
- **Slot** = unidade de conteúdo que precisa ser preenchida.
- **Linhagem** = sequência de tentativas de produção de um mesmo slot.
- **Brief** = planejamento de um artigo antes da escrita.
- **Memória editorial** = preferências aprendidas do histórico.
- **Compliance** = conjunto de regras que o conteúdo deve obedecer.
- **Palavra-chave** = termo central que o artigo busca ranquear. **Principal** = a do artigo; **secundárias** = termos relacionados usados em subtítulos.
- **Meta descrição** = resumo da página exibido nos resultados de busca; deve conter a palavra-chave e um call-to-action.
- **Slug** = parte final e legível da URL do artigo (ex.: `/melhores-cartoes-sem-anuidade`).
- **Canibalização** = dois ou mais artigos do mesmo site disputando a mesma palavra-chave; gera conteúdo duplicado e deve ser evitado.
- **Conteúdo órfão** = artigo sem nenhum link interno apontando para ele.
- **Tag** = rótulo transversal usado para agrupar temas novos sem criar categoria nova.
